# Screenshot Checklist

Save screenshots in:

```text
docs/screenshots/
```

## Required screenshots

Use these exact names:

```text
home.png
question_bank.png
quiz_mode.png
mock_interview.png
coding_exercise.png
review_mode.png
formula_sheet.png
content_dashboard.png
curation_workspace.png
content_workflow.png
```

## Screenshot details

### 1. home.png
Show:
- title
- project snapshot metrics
- main features
- topic coverage

### 2. question_bank.png
Show:
- sidebar filters
- display settings if possible
- one question card
- one expanded answer or derivation

### 3. quiz_mode.png
Show:
- quiz settings
- active question
- progress bar or answer area

### 4. mock_interview.png
Show:
- track selector
- track composition table
- active mock question or summary

### 5. coding_exercise.png
Show:
- exercise filters
- prompt area
- reference solution if possible
- self-assessment buttons

### 6. review_mode.png
Show:
- weak-topic count
- review-list questions

### 7. formula_sheet.png
Show:
- formula search
- formula topic filter
- several formula cards

### 8. content_dashboard.png
Show:
- quality metrics
- topic coverage
- validation checks

### 9. curation_workspace.png
Show:
- curation filters
- curation table
- selected question preview or raw JSON

### 10. content_workflow.png
Show:
- recommended update workflow
- public/private content rule
- suggested folder structure

## Tips

- Use the same browser zoom for all screenshots.
- Keep the sidebar visible when it helps explain the app.
- Use a clean browser window.
- Prefer light mode or dark mode consistently.
- Take screenshots after the app is deployed, not only from local mode.
