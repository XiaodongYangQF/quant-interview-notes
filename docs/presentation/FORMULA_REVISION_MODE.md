# Formula Revision Mode

Version 1.16A adds a dedicated Formula Revision tab.

## Purpose

The Formula Sheet is good for reading. Formula Revision Mode is for active recall.

## Revision modes

### Name → Formula
The app shows the formula name and asks you to recall the formula.

### Formula → Meaning
The app shows the formula and asks you to explain what it means.

## Features

- filter formulas by topic
- search formulas
- generate random formula
- manually load selected formula
- reveal answer after thinking
- self-assessment:
  - Remembered
  - Partially remembered
  - Need review
- download one formula review result as JSON

## Good uses

- quick revision before interviews
- formula memorization
- active recall for probability, statistics, derivatives, Greeks, and stochastic calculus
- checking whether you understand what a formula means, not only what it looks like
