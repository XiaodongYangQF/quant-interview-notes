# Coding Exercise Mode

Version 1.15A adds a dedicated Coding Exercise tab.

## Purpose

The normal Question Bank is useful for reading and searching. Coding Exercise Mode is designed for active coding-interview practice.

## Features

- filter coding questions by category / subtopic
- filter by language
- filter by difficulty and status
- search coding exercises
- generate a random exercise
- manually select an exercise
- reveal reference solution
- show complexity
- show common mistakes and interview tips
- self-assess coding performance
- download one exercise result as JSON

## Good uses

- Python coding practice
- C++ interview preparation
- algorithms revision
- numerical-methods implementation
- quant developer interview preparation
- market-data coding practice
