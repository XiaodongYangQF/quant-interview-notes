## Medium version

I recently built a Quant Interview Trainer using Python and Streamlit.

The goal was to move beyond static PDF notes and create a practical active-recall tool for quantitative finance interview preparation.

The app includes:

- searchable question bank
- formula sheet
- derivations and interview tips
- Python / C++ coding examples
- quiz mode with self-assessment
- review mode for weak questions
- content dashboard and curation workspace
- JSON-based content management workflow

Current topics include probability, statistics, time series, machine learning, derivatives, Greeks, stochastic calculus, coding, numerical methods, and quant developer interview topics.

This project combines my interests in quantitative finance, programming, structured learning, and interview preparation.
